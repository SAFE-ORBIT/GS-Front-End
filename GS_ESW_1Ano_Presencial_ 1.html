🚀 O Contexto: A Nova Corrida Espacial é uma Corrida de Software



O espaço sempre foi território de engenheiros, cientistas e governos. Hoje, ele também é território de desenvolvedores. A nova geração espacial não é movida apenas por foguetes — é movida por código. O software de voo do Falcon 9 da SpaceX roda em Linux. O sistema embarcado do Perseverance opera com 200 milhões de linhas de instruções. O Starlink coordena mais de 6.000 satélites em órbita baixa usando algoritmos de roteamento em tempo real. A corrida espacial do século XXI é, fundamentalmente, um desafio de engenharia de software.

Nunca antes tantas empresas privadas disputaram um espaço que antes era exclusividade de superpotências. SpaceX, Blue Origin, Rocket Lab, Planet Labs, Amazon Kuiper, D-Orbit — são empresas de tecnologia que operam no espaço, não agências governamentais. E esse movimento criou um ecossistema inteiro de oportunidades para quem sabe construir sistemas robustos, escaláveis e inteligentes.

Exemplo: Dados satelitais hoje orientam o agronegócio, antecipam desastres naturais, monitoram desmatamento, conectam regiões remotas e guiam decisões estratégicas em tempo real. A pergunta não é mais "o espaço tem alguma coisa a ver com tecnologia?". A pergunta é: "o que você construiria se tivesse acesso a dados do espaço inteiro?"



Sistemas de Missão

Software de controle e telemetria para satélites e veículos. Precisão de milissegundos em ambientes sem retorno possível.

Dados Orbitais

Imagens satelitais, dados de sensoriamento remoto e APIs espaciais abertas da NASA, ESA e INPE para quem sabe explorar.

Edge em Órbita

Computação embarcada com recursos limitados, latência crítica e ambientes de radiação — o extremo do edge computing.

Conectividade Global

IoT via satélite, comunicação em regiões sem infraestrutura e redes mesh orbitais transformando acesso digital.







🌍 O que Está em Jogo



A economia espacial global superou US$ 630 bilhões em 2023 e deve ultrapassar US$ 1 trilhão até 2030 — impulsionada principalmente por serviços digitais, dados satelitais e comunicação orbital. Não é ficção científica: é um mercado em crescimento acelerado, com demanda real por soluções de software que ainda não existem.

Ao mesmo tempo, problemas críticos da humanidade ainda esperam por respostas tecnológicas: cidades sem cobertura de internet, agricultores sem dados de precisão, emergências climáticas sem monitoramento adequado, operações logísticas cegas para o que acontece em regiões remotas. A tecnologia espacial tem potencial de resolver todos eles — mas precisa de software que conecte o espaço à vida real.

💡 O Desafio



Vocês são uma equipe de engenharia de software contratada para conceber, arquitetar e prototipar uma solução tecnológica real conectada à Indústria Espacial. A solução pode usar dados orbitais, atuar sobre infraestrutura espacial, resolver um problema na Terra usando tecnologias desenvolvidas para o espaço — ou propor um sistema que habilite o próprio ecossistema espacial a funcionar melhor.

O projeto é único para a equipe. Cada disciplina contribuirá com uma camada específica da solução — arquitetura, interface, dados, sustentabilidade, lógica computacional, experiência do usuário. O resultado final deve ser um sistema coeso, não um conjunto de partes separadas. Pensem como engenheiros: cada peça deve se encaixar.

💡 Inspirações de partida (não se limitem a elas): plataforma de análise de imagens satelitais para monitoramento ambiental · sistema de alerta precoce para queimadas ou enchentes via dados orbitais · API de conectividade para IoT em áreas remotas via satélite · dashboard de rastreamento de detritos espaciais · sistema embarcado simulado para operação de nanossatélite · plataforma de dados abertos para agricultores usando sensoriamento remoto · aplicativo para cidadãos usando posicionamento de alta precisão em situações de emergência. O espaço é o limite — literalmente.

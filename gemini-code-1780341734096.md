# BRD: Front-End Design e Web Development - Global Solution 2026

### 1. Restrições do Stack Técnico
* **Permitido:** HTML, CSS e JavaScript Puro.
* **Proibido:** Qualquer framework ou biblioteca Front-End.
* **Arquitetura:** A separação de responsabilidades é obrigatória; HTML, CSS e JS devem residir em arquivos separados dentro de uma estrutura de pastas válida.

### 2. Regras de UI/UX e Estruturais
* **Layout:** Deve ser construído utilizando Flexbox.
* **Estilização:** Uso obrigatório de Variáveis CSS, Reset CSS e Google Fonts. O layout deve ser agradável e pouco poluído, com cores e identidade visual padronizadas.
* **Ativos:** Toda imagem deve incluir o atributo `alt` (penalidade: desconto de 0,5 ponto por imagem sem atributo). Links quebrados de imagens ou CSS resultarão em uma penalidade de 2,5 pontos.
* **Limites de Copywriting:** Os textos devem ser curtos e objetivos. Máximo de 20 palavras por parágrafo. Máximo de 2 parágrafos por seção.

### 3. Arquitetura de Conteúdo
A Landing Page deve conter um menu de navegação, 6 seções distintas e um rodapé.
* **Menu de Navegação:** Deve ser funcional, permitir navegação entre as seções, incluir o nome da equipe ou solução e deixar claro em qual seção o usuário está.
* **Seção 1 (Problema):** Explique qual problema a solução pretende resolver.
* **Seção 2 (Tecnologia):** Apresente quais tecnologias serão utilizadas na solução.
* **Seção 3 (Objetivos):** Descreva os principais objetivos do projeto.
* **Seção 4 (Público-alvo):** Informe quais pessoas ou grupos serão impactados pela solução.
* **Seção 5 (Benefícios):** Mostre os benefícios oferecidos pela proposta.
* **Seção 6 (Aplicação no dia a dia):** Explique como a solução poderá ajudar os usuários na prática.
* **Rodapé:** Deve ser padronizado e conter exclusivamente o primeiro nome e o RM dos integrantes do grupo.

### 4. Funcionalidade Interativa (JavaScript)
* **Troca de Tema:** A página deve ter 3 opções de troca de cor (tema) de fundo.
* **Slideshow:** Deve exibir 3 imagens relacionadas ao tema da Indústria Espacial.
* **Validação de Formulário:** Os formulários devem impedir o envio de campos vazios.
* **Quiz Dinâmico:** Deve conter 10 perguntas sobre o tema e exibir o resultado final para o usuário após a conclusão.
